| 现象 | 判断 | 证据 |

## 2. 实验（本机 Edge 156 headless）

对 `visibilityState=hidden` 的标签页：

| 操作 | 结果 |
|---|---|
| `Page.captureScreenshot(captureBeyondViewport=false)` | **25s 超时** |
| `captureBeyondViewport=true` + `clip=视口` | **25s 超时** |
| `Page.bringToFront` 后再拍 | **0.1s 成功** |

结论：后台页截图的可靠解法是**前台化**，不是换 capture 参数。`Page.bringToFront`
只切标签页、不改变窗口可见性；对离屏身份实例无视觉打扰。

## 3. 实现

### 3.1 截图/点击自动前台化

- `cdp.page_visibility(ws)` 读 `document.visibilityState`；
- `cdp.activate(ws)` 调 `Page.bringToFront`；
- `cdp.shot(..., activate_hidden=True)`：hidden → 前台化 → 拍；
  收据加 `page_visibility` / `activated` / `frame_stale_risk`；
  `activate_hidden=False` 时直接报错（**宁报错不交假图**）。
- `ashot_cdp_click` / `_cdp_drag` 同样：hidden 且 `activate=true` 先前台化，
  收据 `activated`/`page_visibility`；CLI 加 `--no-activate`。

### 3.2 慢 ACK 可观测

- `dispatch` 统计 `events`/`dispatch_ms`/`max_event_ms`；
- `_cdp_click` 补传 stats，收据输出 `planned_ms`/`dispatch_ms`/
  `per_event_ms`；`max_event_ms > 2000` 标 `slow_ack`；
- `_cdp_drag` 同样输出。

### 3.3 snapshot 的 root 与预算

- `snapshot(..., root="#search-content")`：只在该子树内 walk；
  root 不存在 → `RuntimeError("root not found: …")`。
- 预算拆成：`MAX_REFS = max_nodes`（只数 ref），`MAX_NODES = 4×`
  （结构节点上限，防树爆炸）；截断时给
  `truncated_at: {refs, nodes, depth, last_selector}`。
- CLI `snapshot --root`，MCP `ashot_snapshot(root=...)`。

### 3.4 url_sub 选页

- `cdp.ws_for(port, index, url_sub)`：按 URL 子串过滤取第一个；
  找不到明确报错。
- CLI 全部 cdp-* 支持 `--url-sub`；MCP 的 shot/click/drag/eval/snapshot/
  view 支持 `url_sub`（其余工具用 `ws` 精确指定）。

## 4. 测试

- 常规 **188 passed, 6 skipped**。
- `ASHOT_E2E=1`：**6 passed**，新增：
  - 后台页截图：`activated=true`、`visibility=hidden`，改 DOM 后再拍图不同；
  - `snapshot(root="#results", max_nodes=20)`：12 张卡片全部展开、不截断；
    root 不存在报错。

## 5. 边界

- 自动前台化会切换该浏览器内的 active tab（离屏实例无视觉影响；有头可见
  实例会有 tab 高亮变化）；不想切就 `--no-activate`，接受报错。
- `slow_ack` 只上报，不中止（单事件仍受 socket 30s 超时约束）。
- snapshot 的结构节点上限是 4×max_nodes，极端页面仍可能截断（有
  `truncated_at`）。
- `url_sub` 只覆盖常用的 6 个 MCP 工具，其余用 `cdp_tabs` 拿 `ws`。
